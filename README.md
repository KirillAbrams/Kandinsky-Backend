# Сервер Кандинского

Сервер хранит чаты и ставит задания в очередь. Обработчик отправляет задания модели, а служба связи передаёт прогресс и результаты приложениям.

## Запуск

Запусти Docker с Compose. Подготовь адрес работающей службы генерации Кандинского и её ключ доступа. На Windows открой терминал WSL с поддержкой Docker. Запусти команду из корня проекта.

```sh
./tools/dev.sh
```

Введи адрес и ключ по запросу в терминале. Команда проверит генератор, запустит сервер с PostgreSQL и подготовит тестовые чаты. При первом запуске будут скачаны зависимости и около 290 МБ файлов для истории. В конце команда напечатает почту и пароль для местного стенда.

Чтобы остановить сервер и сохранить данные, выполни `./tools/dev.sh stop`. Для своей службы генерации есть [сценарий запуска на Modal](tools/modal_gpu.py). Если нужен запуск с регистрацией по почте, параметры SMTP и секрет для кодов указаны в [примере настроек](.env.example).

## Как проверить генерацию

1. Открой [запросы местного сервера](http://127.0.0.1:8098/docs). Выполни `POST /v1/auth/login` с данными из терминала. Скопируй токен из поля `token` в Authorize.
2. Создай отдельный чат через `POST /v1/threads` и укажи `title`. В `POST /v1/jobs` передай номер чата в `thread_id`, описание в `prompt` и новый ключ в заголовке `Idempotency-Key`. Для фото укажи модель `image`, для видео укажи `video`. Для короткого ролика задай `resolution` со значением `compact` и `duration_seconds` со значением `1`.
3. Подставь `id` задания в `GET /v1/jobs/{job_id}` и проверь его состояние. Когда появится `output_id`, передай его как `asset_id` в `GET /v1/assets/{asset_id}` и открой файл.

## Карта проекта

- Запуск основного сервера, службы связи и модератора. [bootstrap](backend/bootstrap)
- Адреса запросов, проверки входных данных и обработчики. [routes](backend/routes) и [Http](backend/app/Http)
- Логика аккаунтов, чатов, медиа и постановки заданий. [Services](backend/app/Services)
- Обработка очереди и запуск модели на видеокарте. [Jobs](backend/app/Jobs) и [Gpu](backend/app/Services/Gpu)
- Синхронизация чатов, файлов и прогресса с телефонами. [Mobile](backend/app/Services/Mobile)
- Таблицы, права доступа, изменения схемы и стартовые чаты. [Models](backend/app/Models), [Policies](backend/app/Policies) и [database](backend/database)
- Проверки отдельных правил и сценариев целиком. [tests/unit](backend/tests/unit) и [tests/feature](backend/tests/feature)
